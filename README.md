# 广州新房网签数据

每日自动从**广州市住房和城乡建设局 · 阳光家缘 · 房地产项目信息**官方公开接口抓取以下 5 个楼盘的楼栋级网签数据，归档并生成可日期查询的网站。

## 数据来源（仅官方，不引用任何第三方）

- 官网：<https://zfcj.gz.gov.cn/zfcj/fyxx/fdcxmxx/>
- 接口：`https://zfcj.gz.gov.cn/ysqgk/Api/WebApi/fdcxmxxlb.ashx`

## 楼盘 → 阳光家缘官方备案名映射

| 展示名称 | 官方备案名 |
|---|---|
| 珑曜上城 | 珑曜花园 |
| 星汇锦城 | 明颂花园 + 盛颂花园 |
| 繁花里 | 繁花院 |
| 檐屿城 | 檐屿花园 |
| 亚运城环宇熙和 | 官方暂无“熙和/环宇熙和”备案记录，暂以最新在售组团“亚运城B地块B-6~B-9幢住宅（预售证20260088）”代理 |

楼栋名称严格采用阳光家缘官方记录中的项目名称；已网签对应官方“住宅已售套数”，剩余未网签对应“住宅未售套数”，预售总数=已售+未售。

## 文件说明

- `scraper.py`：抓取官方数据，追加写入 `archive.json`
- `build_site.py`：读取 `archive.json`，计算日/周/月环比，生成 `index.html`
- `archive.json`：逐日累积的网签快照（按日期索引）
- `daily.sh`：一键执行抓取 + 生成 + 推送

## 本地运行

```bash
bash daily.sh
```

## 指标口径

- 去化率 = 已网签 ÷ 预售总数
- 日环比 = (今日已网签 − 昨日已网签) ÷ 昨日已网签
- 周环比 = (今日已网签 − 本周一已网签) ÷ 本周一已网签
- 月环比 = (今日已网签 − 本月1日已网签) ÷ 本月1日已网签
